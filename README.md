# teamdynamite/linear-agent

OAuth application manifest for a Linear agent app. Alternatively you could fill out the form by hand on the [create new application](https://linear.app/settings/api/applications/new) page.

Based on documentation found at [https://linear.app/developers/agents]().

The purpose is so our agents can interact with Linear in a way attributed to themselves and not the human user.
